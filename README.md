# Ajouter une exposition

## Avec le formulaire (recommandé)
1. Va sur **https://app.pagescms.org** et connecte-toi avec GitHub.
2. Ouvre le site de la galerie, puis **Expositions** → **Ajouter**.
3. Remplis :
   - **Artiste(s)** — ex. `Claire Dumont` ou `Tom Weiss et Ana Ruiz`
   - **Titre de l'exposition**
   - **Date de début** et **Date de fin**
   - **Photos** — glisse-les ici, dans l'ordre d'affichage
   - **Texte de présentation**
4. Clique sur **Enregistrer**. Le site se met à jour en 1 à 2 minutes.

Pour modifier ou supprimer une expo : ouvre-la dans la liste, change ce que tu veux, enregistre.

## Le classement est automatique
Tu n'as **jamais** besoin de déplacer une expo. Le site regarde la date du jour :
- avant la date de début → **À venir**
- entre le début et la fin → **En cours**
- après la date de fin → **Passées**

La seule chose importante : **des dates justes**.

## Les photos
Avant de les mettre en ligne, réduis-les : environ **2000 pixels de large** maximum, en JPEG.
Une photo de téléphone brute (5–10 Mo) rend le site lent. Sur Mac : ouvre la photo dans Aperçu → Outils → Ajuster la taille.

## Changer l'adresse, l'email ou les horaires
Sur github.com, ouvre le fichier `_config.yml`, clique sur le crayon, modifie le texte entre guillemets, puis **Commit changes**.
